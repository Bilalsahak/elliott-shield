# Elliott Shield

Marketing website for **Elliott Shield** — premium private security serving Seattle and the greater Puget Sound.

**Tagline:** Protection that holds.

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start development server |
| `npm run build`   | Production build         |
| `npm run start`   | Serve production build   |
| `npm run lint`    | Run ESLint               |

## Brand

- **Colors:** Navy `#0B1C2C`, seafoam teal `#3D8B8B`, white, soft slate grays
- **Logo:** `public/logo.png`

## Notes

- Single-page marketing site with section anchors
- Contact form uses client-side validation and a success state (no backend)
